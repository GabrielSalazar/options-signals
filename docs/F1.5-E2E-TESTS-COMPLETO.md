## 🎯 Estratégia E2E

**Locator Strategy:**
- Prefer semantic HTML (`[role="row"]`, `[aria-label]`)
- Fallback to data attributes (`[data-testid]`)
- Then to text content (`.locator('text=/pattern/i')`)
- Avoid brittle selectors (CSS classes, IDs)

**Timeout Handling:**
- 3-5s for UI elements (modals, panels)
- 10s for network operations (backtest results)
- Dynamic waits with `.isVisible()` / `.waitForLoadState()`

**Error Handling:**
- Graceful fallbacks with `.catch(() => false)`
- Clear error messages with `.toContain('error')`
- Network error simulation with `page.route()`

## 🚀 Como Rodar E2E Tests

**Setup (primeira vez):**
```bash
npm install -D @playwright/test
npx playwright install
```

**Rodar todos E2E tests:**
```bash
npx playwright test tests/e2e
```

**Rodar com UI:**
```bash
npx playwright test tests/e2e --ui
```

**Rodar um spec específico:**
```bash
npx playwright test tests/e2e/market-view.spec.ts
```

**Gerar report:**
```bash
npx playwright show-report
```
